# Tiles viewer

A browser viewer for PMTiles, MBTiles, TileJSON, XYZ tiles, and VTPK/TPKX.

The hosted viewer is at [https://viewer.gishub.vn](https://viewer.gishub.vn).

## Run locally

Node.js 22.12 or newer is required.

From this directory:

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

To check the production build locally:

```bash
npm run build
npm run preview
```
